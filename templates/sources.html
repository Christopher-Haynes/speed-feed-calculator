Data sources

Every value in the data records where it came from, the page, table or link, the date it was checked, and a confidence level. When more than one source covers the same cut, the calculator uses shop-verified data first, then manufacturer, then handbook, and lists the others to cross-check.

Confidence levels

  • shop-verified Run on a real machine and logged.
  • manufacturer From a tool or machine maker's published data, for their own products.
  • handbook From a published machining reference.
